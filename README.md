# student-result-checker
Student Result Checker

About the Project

Student Result Checker is a simple frontend web application that allows users to enter student information and academic scores. It calculates the total score and assigns a grade based on predefined grading rules.

Features

- Student name input.
- Matriculation number input.
- Course code and course title fields.
- Continuous Assessment (CA) score input.
- Examination score input.
- Automatic total score calculation.
- Automatic grade assignment.
- Result display section.

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Use

1. Open the website in a web browser.
2. Enter the student's name and matriculation number.
3. Enter the course information.
4. Enter the CA and examination scores.
5. Click the Check Result button.
6. View the calculated total score and grade.

Grading System

The project uses example grading thresholds for demonstration purposes. These can be modified to match an institution's official grading system.

Purpose of the Project

The project demonstrates how frontend technologies can be used to create an interactive academic result-checking interface. It also provides practice with HTML forms, CSS styling, JavaScript functions, input validation, and basic calculations.

Limitations

This version does not use a database or verify official academic records. Results are calculated in the browser from the scores entered by the user.

Future Improvements

- Support for multiple courses.
- GPA calculation.
- Improved mobile responsiveness.
- Connection to a secure backend and database.
